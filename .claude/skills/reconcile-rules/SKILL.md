# Reconcile the agent context layer

Paths are relative to the target repository root. Read `AGENTS.md` and the comments
and source-control policies. This workflow does not grant access to unrelated memory
or authorize deleting user preferences.

1. Inventory root/scoped instructions, installed project skills and explicitly scoped
   memory. Verify factual claims against the tree before proposing replacements.
2. Classify: intent/standing rule → AGENTS; cross-cutting constraint → policy;
   current behavior → system doc/docstring; procedure → skill/script; unfinished
   work → task; aspiration → vision; duplicate/obsolete → removal.
3. Record contradictions and preserve genuine user preferences and owner rulings.
   Keep scoped framework-generated instructions under their generating tool's control.
4. Write the destination first, check that it preserves the useful constraint, then
   remove duplication from owned source files. Update pointers and discovery metadata.
5. Inspect every changed file and verify references. Archive/remove memory only when
   explicitly in scope and after checking its replacement; preserve unknown ownership.
6. Report what moved, what was removed, unresolved contradictions and verification.
